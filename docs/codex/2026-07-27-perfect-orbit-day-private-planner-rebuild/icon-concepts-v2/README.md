Status: Day Compass is selected and in platform production.

All ten assets were generated independently from a blank brief. They do not use
the previous launcher mark as a reference. Each PNG is exactly 512 × 512,
contains no lettering, and uses a normalized flat chroma background so the
selected mark can be isolated without guessing at the canvas colour.

## Selection gate

The selected mark must pass this production gate:

1. remove chroma and manually clean colour spill at the silhouette edge;
2. normalize the geometry and optical centre on a transparent 512 × 512 master;
3. verify recognition at 16, 24, 32, 48 and 64 px;
4. derive Android legacy, adaptive foreground and monochrome variants;
5. derive a multi-resolution transparent Windows ICO;
6. verify the installed result in Pixel Launcher, the Android widget picker,
   Windows Explorer, the taskbar and the running window;
7. update screenshots, platform contracts and identity documentation only after
   the installed artifacts match the selected source.
